Slide 6

Backend layers

Edge & API Gateway

  • HTTP API public HTTPS; throttle ~50 r/s, burst 100
  • HTTP proxy to ALB — cleartext hop until ACM + DNS (4G)
  • WAF managed rules + IP rate limit on ALB

ECS Fargate

  • Service malcon-nexus-api, task malcon-nexus-api:6
  • Private subnets, no public task IP
  • Image: aws-api/ wraps worker/src/app.ts
  • PG via clientPg.ts; S3 via s3Storage.ts

Slide 7

Slide 15

One-minute summary

  • Staff use a Hostinger-hosted React PWA that talks only to the AWS HTTP API in Mumbai.
  • Traffic passes API Gateway and WAF-protected ALB into private ECS running the shared Worker app codebase.
  • Data lives in encrypted RDS PostgreSQL; files in three private S3 buckets via authenticated API routes.
  • JWT auth is fail-closed; secrets load from Secrets Manager at task start.
  • Release is production ready with documented deferrals (gallery/TV tokens, east-west TLS, SNS subscribers).
