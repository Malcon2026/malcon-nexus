Section 1

Hero and architecture at a glance

Browser loads the Vite/React SPA from Hostinger → HTTPS JSON to API Gateway → WAF on ALB → private ECS (port 8080) → encrypted PostgreSQL RDS and scoped S3 buckets.

Production URLs

  • SPA: https://app.malconnexus.com
  • API: https://njbtfquxeh.execute-api.ap-south-1.amazonaws.com

Release posture

Production ready Deferred items

Per frontend release notes and Phase 4I: certified with accepted deferrals (TLS hop, SNS subscribe, JWT cleanup window).

Section 4

Frontend (Hostinger SPA)

Stack

  • React 19, TypeScript, Vite 7, Tailwind 4
  • Zustand · Framer Motion · Recharts
  • PWA service worker (webPush.ts)
  • vite-plugin-singlefile; gallery/TV separate Vite configs

Production env

  • VITE_USE_AWS_BACKEND=true
  • VITE_USE_CLOUDFLARE_BACKEND=false
  • VITE_WORKER_API_URL → API Gateway

Dev may use 127.0.0.1:8787 via workerReadConfig.ts.

Product surfaces

Cases, workflow, attendance, HR, expenses, petrol, food, KMS, hospitals, doctors, Telegram, reports, settings. Employee shell with bottom nav. Bundles: /gallery, /tv kiosk; in-app TvBoard for logged-in admins.

Section 5

Edge and API Gateway

  • HTTP API public HTTPS; throttle ~50 r/s, burst 100 (4F).
  • HTTP proxy to ALB — cleartext hop until ACM + DNS (4G deferred).
  • WAF malcon-nexus-api-edge on ALB (managed rules + IP rate limit).
  • WAF not on HTTP API stage (REST ARN limitation); ALB covers proxied traffic.

Not verified live Listener details if changed after Phase 4I capture.

Section 6

Compute (ECS)

Service

  • Service malcon-nexus-api, task malcon-nexus-api:6
  • Private subnets, no public task IP
  • Image from aws-api/ wrapping worker/src/app.ts

Runtime

  • PostgreSQL via clientPg.ts when DATABASE_URL set
  • S3 via s3Storage.ts with three bucket env vars
  • CORS from API_CORS_ORIGIN in SM

Section 7

  • Schema/migration from D1 via scripts/aws/migrate-d1-to-postgres.mjs.

Section 9

Authentication and authorization

Browser

  • workerAuthClient.ts — login, OTP, me
  • Token: malcon_nexus_access_token
  • workerApi.ts Bearer headers
  • Supabase stubbed on AWS path

API

  • JWT from SM; dual-verify window (4H) until legacy segment removed
  • Public: health, auth login/OTP, webhook with secret
  • 401 fail-closed; dev identity header blocked in prod
  • Role checks in middleware/routes (4H IDOR fixes)
