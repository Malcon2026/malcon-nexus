Location punchin

Field staff log a trip with two GPS punches. The app calculates the km. Admin can re-check the spots on Google Maps.

This is not office attendance and not petrol. Separate tab on the employee home: Location punchin.

What the boy does
  • Open Location punchin (not Punch in / out)
  • Notes → Start location → travel → Reached
  • One open trip at a time — must press Reached before the next start
What you can check
  • Admin Attendance → Today lists each trip
  • Plus Code opens the exact pin in Google Maps
  • GPS accuracy is shown (e.g. ±12 m) so a weak indoor punch is obvious

Km is straight-line GPS (start pin to end pin), not the speedometer. Petrol still uses meter photos.
